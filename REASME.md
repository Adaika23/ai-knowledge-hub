# AI Knowledge Hub

A full-stack AI-powered knowledge management application that allows users to create notes, search notes, and ask questions using an AI assistant.

## Features

- Create and store notes
- Search notes
- AI Assistant connected to FastAPI backend
- React frontend with reusable components
- FastAPI backend with REST API endpoints

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Python
- FastAPI
